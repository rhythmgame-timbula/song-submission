01

Timbulaについて

Timbulaは、星と宇宙をテーマにしたブラウザ音楽ゲームです。 さまざまな楽曲と多彩なノーツを通して、音楽とリズムを楽しめるゲームを目指しています。

ゲームの詳しい遊び方や雰囲気については、紹介動画をご覧ください。

COMING SOON

ゲーム紹介動画を2026年9月中に公開予定

02

募集部門

GENERAL

一般部門

自由なジャンルで曲を募集します（本作の雰囲気に合わせる必要はありません)。

高難易度向けの楽曲はもちろん、中・低難易度向けの楽曲も大歓迎です。

Timbulaに、新たな星を加えましょう！

RELEASED

既発部門

既に公開されている楽曲を募集します。

ジャンルも自由なので、どんな曲でもご応募いただけます。

皆さんの星を、蘇らせてください！

NEBULA

星雲部門

宇宙や星をテーマにした高難易度向けの楽曲を募集します。

楽曲のクオリティはもちろん、「テーマに即しているか」という点を審査で他の観点より重く見ます。

渾身の「宇宙音ゲー曲」をお待ちしています！

03

募集要項

一般部門 +

募集期間

8月21日(金)～11月1日(日) 23:59 (UTC+9)

応募資格

年齢や居住地などに関係なく、全ての人が応募可能です。
18歳未満の方は、保護者の承諾の上でご応募ください。
また、連絡の際は日本語での対応をお願いいたします（翻訳サービス等を使用しても構いません)。
Please communicate in Japanese (you may use translation services or similar tools).
연락시에는 일본어로의 대응을 부탁드리겠습니다 (번역 서비스 등을 사용해도 상관없습니다).
请用日语交流 (您可以使用翻译服务等)。

応募規定

  • 応募には、本募集要項への同意が必要です。
  • Timbulaのオリジナル曲として収録するため、応募楽曲は未公開のものに限ります。
    新規に制作する楽曲はもちろん、作り溜めしている楽曲や、過去に他の公募等で落選となった楽曲でも構いません。
    すでに公開済みの楽曲を応募する際は「既発部門」で応募してください。
  • 採用楽曲は非独占的ライセンスのもとでTimbulaに収録し、Timbula運営はその楽曲を自由に複製、翻案、改変等して使用できます。
    また、自らの裁量で楽曲の使用許諾等をすることができます。ただし、著作権の譲渡は行いません。
    Timbulaのオリジナル曲として収録するため、他の作品（ゲームやアルバム等）への収録は原則としてご遠慮ください（事前に相談いただければ許可を出せる場合もございます)。
  • 非商用ゲームにつき、金銭的報酬はお渡しできません。申し訳ございません。
  • 以下に該当する楽曲の応募は禁止します。
    －応募者本人が著作権を保有していないもの
    －権利を第三者に譲渡しているものや、JASRAC等の著作権管理団体に信託しているもの
    －第三者の楽曲等を許可なく使用したもの
    －楽曲の全部・または大部分をAIによって生成したもの
    例えば、AIを使用したプラグイン（iZotope Ozone等）を活用する、コード進行や歌詞の表現をAIに提案してもらう、等は可能です。
    しかし、音楽生成AI（Suno等）に楽曲を生成してもらう、歌詞やメロディー等の全部・または大部分をAIに考えてもらう、等は不可能です。
    AIの使用により万が一問題が生じた場合、当方では一切の責任を負いかねます。
  • 応募の際、音声合成ソフト（VOCALOID、Synthesizer V、CeVIO 等）の使用も認めますが、音声及びキャラクター名の「非営利かつ無償」の使用が許可されていることを確認してください。
    万が一権利関係の問題が生じた場合、当方では一切の責任を負いかねます。

応募楽曲について

  • 楽曲の長さは2～3分にしてください。規定範囲外の楽曲でも応募を受け付けますが、規定範囲を5秒以上外れる楽曲は、審査の際に外れた長さに伴い減点します。
  • 途中でBPMが変化しても構いませんが、連続的なBPM変化は禁止します（瞬時にBPMが変わる非連続的なもののみ可)。その他、BPMの制限はありません。
  • 楽曲は、インスト楽曲、ボーカル楽曲を問いません。
  • ボーカルの有無は審査に影響しませんが、ボーカル楽曲の場合、歌詞の内容は審査に（僅かながら）影響する場合があります。
  • 楽曲のジャンルや雰囲気は問いません。
  • マスタリング済みのデータをご応募ください。
  • 音源の提出の際は、「楽曲名.mp3」というファイル名の、192kbps MP3ファイルにしてください。
    ファイル名の中の「楽曲名」には応募楽曲のタイトルが入りますから、タイトルが『楽曲名』でない限りは「楽曲名.mp3」というファイル名をそのまま使わないでください。
  • ボーカル楽曲の際は、歌詞を「楽曲名.txt」というファイル名のテキストファイルで提出する必要があります。
    ファイル名の中の「楽曲名」には応募楽曲のタイトルが入りますから、タイトルが『楽曲名』でない限りは「楽曲名.txt」というファイル名をそのまま使わないでください。

注意事項

  • 楽曲制作関係者が複数いる場合、本募集要項への関係者全員の同意が必要です。
  • 同一部門への応募は1人につき2曲までとし、合作等での参加や異なる名義での応募も1曲と数えます。また、星雲部門に一般部門と同じ楽曲を応募することはできません。
    なお、同一人物による受賞は、一部門につき1曲、全部門合計で2曲以内とします。
  • 以下に該当する楽曲は選考対象外とする可能性があります。
    － 本募集要項に反しているもの
    － 第三者が創作した著作物を複製、翻案、改変等して創作されたもの(Remixなどを含む)
    － 第三者の権利を侵害するもの及び侵害するおそれのあるもの
    － 公序良俗に反するもの
    － 第三者に応募楽曲の使用を許可しているもの
    － その他不適切だと判断されたもの

採用楽曲について

独自の審査基準のもと100点満点の審査を行い、部門別で点数が高い楽曲を規定数採用します（場合によっては満点を超過することがあります)。
また、各部門の最も点数が高い楽曲の中で最も点数が高い曲を1st Prize、その他2曲を2nd Prizeとします。
その際、星雲部門のみ審査基準が若干異なるので、星雲部門の最高点楽曲は一般・既出部門の審査基準のもとで再審査します。

審査後について

審査終了後、採用となった曲の作曲者には、「仮採用」のメールを応募フォームにて入力していただいたメールアドレス宛に送信します。
その際、rhythm.timbula[at]gmail.com（[at]を@に変換）からのメールを受信できるようにしてください。
そのメールに記載されている方法での、以下のファイルのアップロードをもって本採用とします。

  • マスタリング済みの音源（48kHz、24bitのWAVEファイル）
  • 未マスタリングの2mix音源（48kHz、24bitのWAVEファイル）
  • サンプルを除いた全パートのMIDIファイル（Standard MIDI File Format 1）
  • プロジェクトファイルを開いている状態のDAW画面のスクリーンショット
  • 「曲名」「制作者名義」「BPM（変動がある場合は詳細に)」「使用プラグイン及びサンプル（主要なもののみ)」「その他クレジット」をすべてまとめたテキストファイル

なお、応募後に若干の修正・ブラッシュアップをしても構いません。

採用者全員へのメールの送信を終え次第、Timbula公式X（@Rhythm_Timbula）で告知を行います。その告知日から7日が経過してもファイルのアップロードまたはメールへの返信がない場合、改めてメールを送信させていただきます。再送信日からさらに7日（告知日から14日）が経過してもファイルのアップロードまたはメールへの返信がない場合、仮採用は取り消しとなります。
もし仮採用が取り消された場合には、繰り上げ採用を行います。

本採用曲が確定次第、本ページ及びTimbula公式Xにて採用者発表を行います。
採用者発表があるまで、採用者はSNS等での採用報告をすることができません。
また、採用者発表があっても、ゲーム内に採用楽曲が収録されるまで、採用者は音源の公開をすることができません。
採用発表前の採用報告や収録前の音源公開をしていたことが発覚した場合、採用は取り消しとなります。
また、その他本募集要項に反する事案が確認された場合、本採用後であっても採用は取り消しとなります。
本採用が取り消された場合には、繰り上げ採用は行いません。

採用曲に対しては本ページ上にて審査員からのコメントを公開します。
また不採用曲に対しても、次のいずれかに当てはまるものについてはコメントをメールで送信します。
①入賞最低点数との差が5以内である楽曲
②審査において強い魅力を感じた楽曲

免責事項

応募者は、自己の責任と負担において本楽曲公募に参加するものとします。
本募集要項は、事前予告なく改訂される場合があります。
本楽曲公募は、事前予告なく休止・中止される場合があります。
本楽曲公募により発生した、いかなる損害・紛争等について、当方は一切の責任を負いません。

    また、自らの裁量で楽曲の使用許諾等をすることができます。ただし、著作権の譲渡は行いません。
    Timbulaのオリジナル曲として収録するため、他の作品（ゲームやアルバム等）への収録は原則としてご遠慮ください（事前に相談いただければ許可を出せる場合もございます)。
  • 非商用ゲームにつき、金銭的報酬はお渡しできません。申し訳ございません。
  • 以下に該当する楽曲の応募は禁止します。
    －応募者本人が著作権を保有していないもの
    －権利を第三者に譲渡しているものや、JASRAC等の著作権管理団体に信託しているもの
    －第三者の楽曲等を許可なく使用したもの
    －楽曲の全部・または大部分をAIによって生成したもの
    例えば、AIを使用したプラグイン（iZotope Ozone等）を活用する、コード進行や歌詞の表現をAIに提案してもらう、等は可能です。
    しかし、音楽生成AI（Suno等）に楽曲を生成してもらう、歌詞やメロディー等の全部・または大部分をAIに考えてもらう、等は不可能です。
    AIの使用により万が一問題が生じた場合、当方では一切の責任を負いかねます。
  • 応募の際、音声合成ソフト（VOCALOID、Synthesizer V、CeVIO 等）の使用も認めますが、音声及びキャラクター名の「非営利かつ無償」の使用が許可されていることを確認してください。
    万が一権利関係の問題が生じた場合、当方では一切の責任を負いかねます。

応募楽曲について

  • 宇宙や星をテーマにした高難易度向けの楽曲を応募してください。
  • 楽曲の長さは2～3分にしてください。規定範囲外の楽曲でも応募を受け付けますが、規定範囲を5秒以上外れる楽曲は、審査の際に外れた長さに伴い減点します。
  • 途中でBPMが変化しても構いませんが、連続的なBPM変化は禁止します（瞬時にBPMが変わる非連続的なもののみ可)。その他、BPMの制限はありません。
  • 楽曲は、インスト楽曲、ボーカル楽曲を問いません。
  • ボーカルの有無は審査に影響しませんが、ボーカル楽曲の場合、歌詞の内容は審査に（僅かながら）影響する場合があります。
  • マスタリング済みのデータをご応募ください。
  • 音源の提出の際は、「楽曲名.mp3」というファイル名の、192kbps MP3ファイルにしてください。
    ファイル名の中の「楽曲名」には応募楽曲のタイトルが入りますから、タイトルが『楽曲名』でない限りは「楽曲名.mp3」というファイル名をそのまま使わないでください。
  • ボーカル楽曲の際は、歌詞を「楽曲名.txt」というファイル名のテキストファイルで提出する必要があります。
    ファイル名の中の「楽曲名」には応募楽曲のタイトルが入りますから、タイトルが『楽曲名』でない限りは「楽曲名.txt」というファイル名をそのまま使わないでください。

注意事項

  • 楽曲制作関係者が複数いる場合、本募集要項への関係者全員の同意が必要です。
  • 同一部門への応募は1人につき2曲までとし、合作等での参加や異なる名義での応募も1曲と数えます。また、星雲部門に一般部門と同じ楽曲を応募することはできません。
    なお、同一人物による受賞は、一部門につき1曲、全部門合計で2曲以内とします。
  • 以下に該当する楽曲は選考対象外とする可能性があります。
    － 本募集要項に反しているもの
    － 規定テーマを著しく逸脱していると判断されたもの
    － 第三者が創作した著作物を複製、翻案、改変等して創作されたもの(Remixなどを含む)
    － 第三者の権利を侵害するもの及び侵害するおそれのあるもの
    － 公序良俗に反するもの
    － 第三者に応募楽曲の使用を許可しているもの
    － その他不適切だと判断されたもの

採用楽曲について

独自の審査基準のもと100点満点の審査を行い、部門別で点数が高い楽曲を規定数採用します（場合によっては満点を超過することがあります)。
また、各部門の最も点数が高い楽曲の中で最も点数が高い曲を1st Prize、その他2曲を2nd Prizeとします。
その際、星雲部門のみ審査基準が若干異なるので、星雲部門の最高点楽曲は一般・既出部門の審査基準のもとで再審査します。

審査後について

審査終了後、採用となった曲の作曲者には、「仮採用」のメールを応募フォームにて入力していただいたメールアドレス宛に送信します。
その際、rhythm.timbula[at]gmail.com（[at]を@に変換）からのメールを受信できるようにしてください。
そのメールに記載されている方法での、以下のファイルのアップロードをもって本採用とします。

  • マスタリング済みの音源（48kHz、24bitのWAVファイル）
  • 未マスタリングの2mix音源（48kHz、24bitのWAVファイル）
  • サンプルを除いた全パートのMIDIファイル（Standard MIDI File Format 1）
  • プロジェクトファイルを開いている状態のDAW画面のスクリーンショット
  • 「曲名」「制作者名義」「BPM（変動がある場合は詳細に)」「使用プラグイン及びサンプル（主要なもののみ)」「その他クレジット」をすべてまとめたテキストファイル

なお、応募後に若干の修正・ブラッシュアップをしても構いません。

採用者全員へのメールの送信を終え次第、Timbula公式X（@Rhythm_Timbula）で告知を行います。その告知日から7日が経過してもファイルのアップロードまたはメールへの返信がない場合、改めてメールを送信させていただきます。再送信日からさらに7日（告知日から14日）が経過してもファイルのアップロードまたはメールへの返信がない場合、仮採用は取り消しとなります。
もし仮採用が取り消された場合には、繰り上げ採用を行います。

本採用曲が確定次第、本ページ及びTimbula公式Xにて採用者発表を行います。
採用者発表があるまで、採用者はSNS等での採用報告をすることができません。
また、採用者発表があっても、ゲーム内に採用楽曲が収録されるまで、採用者は音源の公開をすることができません。
採用発表前の採用報告や収録前の音源公開をしていたことが発覚した場合、採用は取り消しとなります。
また、その他本募集要項に反する事案が確認された場合、本採用後であっても採用は取り消しとなります。
本採用が取り消された場合には、繰り上げ採用は行いません。

採用曲に対しては本ページ上にて審査員からのコメントを公開します。
また不採用曲に対しても、次のいずれかに当てはまるものについてはコメントをメールで送信します。
①入賞最低点数との差が5以内である楽曲
②審査において強い魅力を感じた楽曲
